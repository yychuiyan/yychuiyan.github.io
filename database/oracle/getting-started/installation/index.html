第2章 · 安装与配置 ​

本章目标 ​

读完这一章，你会：

  1. 在自己的电脑上成功安装 Oracle 环境（Windows 直接安装 / Mac 用 Docker）
  2. 学会如何干净卸载（装坏了也不怕）
  3. 认识 Oracle 自带的三个工具：SQL*Plus、SQL Developer、OEM

安装是很多新手的第一道坎。本章会把每一步拆开讲清楚，跟着走就能装好。

2.1 安装前的准备 ​

2.1.1 硬件要求 ​

项目最低要求推荐配置
内存4 GB8 GB 以上
硬盘空闲空间10 GB20 GB 以上
CPU双核四核以上
操作系统Windows 7 SP1 (64位)Windows 10/11 (64位)

Oracle 比较吃内存。如果你电脑只有 4GB 内存，安装后 Oracle 的后台进程会占用约 1~1.5GB，可能让系统变慢。建议至少 8GB。

2.1.2 软件准备 ​

你需要下载 Oracle Database 12c 的安装包。打开浏览器，搜索 "Oracle Database 12c Download"，进入 Oracle 官方下载页面。

下载时注意两点：

  • 选 Windows x64 版本
  • 文件大约 2.5~3GB，下载需要一些时间

下载完成后，你会得到一个 zip 压缩包，将它解压到一个路径中没有中文和空格的目录下，比如 D:\oracle_install。

为什么路径不能有中文和空格？Oracle 安装程序在解析路径时可能出错，这是无数人踩过的坑。

2.1.3 关闭不必要的程序 ​

安装前建议：

  • 关闭杀毒软件（可能误拦 Oracle 的服务注册）
  • 关闭防火墙（或者在安装过程中允许 Oracle 通过）
  • 以管理员身份运行安装程序

2.1.4 Mac 用户的特别说明 ​

Oracle 数据库没有提供 Mac 版的原生安装程序。Mac 用户有以下选择：

方案难度推荐度
Docker 运行 Oracle⭐⭐✅ 推荐，轻量，随用随开
虚拟机 + Windows⭐⭐⭐性能开销大
连接远程服务器⭐需要额外机器

本章 Mac 部分采用 Docker 方案，因为它是 Mac 上最主流、最轻量的 Oracle 学习方式。

如果你不想装 Docker，也可以直接用第 3 方在线 Oracle 练习平台（如 LiveSQL），跳过本章安装步骤。

2.2 Windows 安装 Oracle 12c ​

第一步：启动安装程序 ​

进入解压后的文件夹，找到 setup.exe，右键 → 以管理员身份运行。

启动后会先弹出一个黑框（这是 Oracle 在检查系统环境），稍等片刻就会出现图形安装界面。

第二步：配置安全更新 ​

第一个界面询问是否通过 My Oracle Support 接收安全更新。取消勾选，点击下一步。

系统会弹出一个警告 "未提供电子邮件地址"，直接点 "是" 跳过即可。

第三步：选择安装选项 ​

这里有三个选项：

选项说明
创建和配置数据库安装软件 同时 创建一个数据库（推荐新手选这个）
仅安装数据库软件只装软件，数据库之后手动建
升级现有数据库给老版本升级

选择第一个："创建和配置数据库"，点击下一步。

第四步：选择系统类型 ​

选项说明
桌面类适合个人学习和开发，配置简单
服务器类适合生产环境，配置项更多

选 "桌面类"，这是我们学习和开发用的。

第五步：配置数据库 ​

这是最关键的一步，需要填写几个信息：

Oracle 基目录（Oracle Base）：Oracle 软件的安装位置。默认在 C:\app\你的用户名。如果 C 盘空间紧张，可以改到 D 盘，比如 D:\app\oracle。

建议：路径中不要有中文和空格。D:\app\oracle 可以，D:\我的软件\oracle 不行。

数据库版本：选择 "标准版 (Standard Edition)" 或 "企业版 (Enterprise Edition)"。学习用标准版就够了，功能完全覆盖本教程所有内容。

全局数据库名：给数据库起个名字，默认是 orcl。就用这个默认名，全书记忆方便。

管理口令：这是 SYS 和 SYSTEM 用户的密码，相当于数据库的 "root 密码"。

密码规则：至少 8 位，包含大小写字母和数字。比如 Oracle123。一定要记住这个密码！ 忘了虽然能改，但挺麻烦。

可插拔数据库名（PDB）：默认是 orclpdb，保持不变。

填好之后点下一步。

第六步：环境检查 ​

安装程序会自动检查你的电脑是否满足安装条件。如果某些检查项警告（黄色三角），通常不影响安装，可以忽略。

常见警告：物理内存不足、网络配置未设置静态 IP。学习环境均可忽略。

确认无红色错误后，点击 "安装"。

第七步：等待安装 ​

安装过程一般需要 15~30 分钟，具体取决于电脑配置。进度条可能会在某个百分比停留很久（比如 50% 附近），这是正常的，Oracle 在创建数据库，不要强制关闭。

如果安装超过 1 小时还没完成，先检查杀毒软件是否拦截，再看安装日志（一般在 C:\Program Files\Oracle\Inventory\logs 下）。

第八步：安装完成 ​

安装成功后，会弹出 "Database Configuration Assistant" 的完成界面，显示：

  • 全局数据库名：orcl
  • 系统标识符 (SID)：orcl
  • 企业管理器 URL：https://localhost:5500/em

把这些信息截图保存，后面会用到。

点击关闭，安装完成！

2.2.1 验证安装是否成功 ​

打开 命令提示符（cmd），输入：

bash
sqlplus / as sysdba

如果出现 SQL> 提示符，恭喜你，安装成功！

sql
-- 看看数据库状态
SQL> SELECT STATUS FROM V$INSTANCE;

STATUS
------------
OPEN

看到 OPEN 就说明数据库正在运行。输入 exit 退出。

如果提示 "sqlplus 不是内部或外部命令"，说明环境变量没配好。别急，可以先到 Oracle 安装目录下的 bin 文件夹里运行，比如 D:\app\oracle\product\12.2.0\dbhome_1\BIN\sqlplus.exe。

2.3 Mac 安装 Oracle（Docker 方式） ​

由于 Oracle 没有 Mac 原生安装包，我们通过 Docker 来运行 Oracle 数据库。

2.3.1 安装 Docker ​

如果你的 Mac 还没装 Docker，先去官网下载 Docker Desktop for Mac：

  1. 访问 docker.com 下载 Docker Desktop
  2. 根据你的 Mac 芯片选择版本：
    • Apple Silicon（M1/M2/M3/M4）：选 Apple Chip 版本
    • Intel 芯片：选 Intel Chip 版本
  3. 下载后把 Docker 图标拖进 Applications 文件夹，双击运行
  4. 启动后屏幕顶部菜单栏会出现鲸鱼图标 🐳

验证 Docker 安装：

bash
docker --version
# Docker version 24.x.x, build ...

docker ps
# CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
# (如果是空的也没关系，说明 Docker 正常运行)

2.3.2 拉取并启动 Oracle 容器 ​

Oracle 官方提供了 Docker 镜像，我们用社区维护的 gvenzl/oracle-xe 轻量镜像：

bash
# 拉取 Oracle XE 镜像（slim 版本更小，下载更快）
docker pull gvenzl/oracle-xe:21.3.0-slim

# 创建并启动容器
docker run -d \
  --name oracle12c \
  -p 1521:1521 \
  -p 5500:5500 \
  -e ORACLE_PASSWORD=Oracle123 \
  gvenzl/oracle-xe:21.3.0-slim

参数解释：

参数含义
-d后台运行容器
--name oracle12c给容器起个名字，方便管理
-p 1521:1521映射数据库端口到本机
-p 5500:5500映射 OEM 管理端口到本机
-e ORACLE_PASSWORD=Oracle123设置 SYS 和 SYSTEM 的密码

21.3.0-slim 是精简版（约 2GB），下载快、占空间小，学习完全够用。如果你想装完整版，把 slim 换成 full 即可。

如果拉取失败：国内访问 Docker Hub 经常不稳定，报 Service Unavailable 或超时。解决方案：

方案一：配置国内镜像加速（推荐）

打开 Docker Desktop → 设置（⚙️）→ Docker Engine，在 registry-mirrors 中加入以下镜像源：

json
{
  "registry-mirrors": [
    "https://docker.xuanyuan.me",
    "https://docker.1ms.run",
    "https://docker.m.daocloud.io",
    "https://docker.1panel.live"
  ]
}

点击 "Apply & Restart"，等 Docker 重启后再执行 docker pull。

配置多个镜像源做冗余，Docker 会自动选最快的。不要用中科大、网易等旧镜像，它们 2024~2025 年已陆续停服。

方案二：使用代理

如果你有科学上网工具，在终端中设置代理后再拉取：

bash
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
docker pull gvenzl/oracle-xe:21.3.0-slim

方案三：备选镜像

如果上述方案都不行，试试 Oracle 官方镜像（需要注册 Oracle 账号）：

bash
# 先去 container-registry.oracle.com 注册并登录
docker login container-registry.oracle.com
docker pull container-registry.oracle.com/database/express:21.3.0-xe

首次启动需要 1~3 分钟来创建数据库。用 docker logs oracle12c 查看进度，看到 DATABASE IS READY TO USE! 就说明好了。

2.3.3 验证容器状态 ​

bash
# 查看容器是否在运行
docker ps | grep oracle12c

# 如果 STATUS 显示 "Up X minutes" 且状态为 "healthy"，说明 OK

2.3.4 进入容器使用 SQL*Plus ​

bash
# 进入容器内部
docker exec -it oracle12c bash

# 在容器内连接数据库
sqlplus system/Oracle123

# 看到 SQL> 提示符，安装成功！
SQL> SELECT STATUS FROM V\$INSTANCE;

STATUS
------------
OPEN

SQL> exit

输入 exit 退出容器，回到 Mac 终端。

2.3.5 启动和停止容器 ​

容器不需要一直开着，不用时可以停掉，用的时候再启动：

bash
# 停止 Oracle 容器
docker stop oracle12c

# 下次要用了再启动
docker start oracle12c

# 容器启动后等几秒数据库就 ready 了
docker ps | grep oracle12c

停止容器不会丢失数据，数据存在容器内部。除非你删除了容器（docker rm），否则建的表、插入的数据都在。

2.3.6 Mac 上使用 SQL Developer ​

虽然在 Mac 上装了 Docker Oracle，但 SQL Developer 和 SQL*Plus 可以用 Mac 原生客户端，更方便：

方案一：Docker 容器内 SQL*Plus（免费，已可用）

bash
docker exec -it oracle12c sqlplus system/Oracle123

方案二：安装 Mac 版 SQL Developer（免费）

  1. 去 Oracle 官网下载 SQL Developer for Mac
  2. 解压后双击运行
  3. 新建连接：Hostname 填 localhost，Port 填 1521，SID 填 XE（注意和 Windows 不同，容器里默认是 XE）

方案三：用 VS Code 插件

安装 VS Code 插件 "Oracle SQL Developer Extension" 或 "Oracle Explorer"，在 VS Code 里直接写 SQL。

本教程推荐方案二，和 Windows 同学用同样的界面，交流起来不混乱。

2.3.7 卸载 Docker Oracle ​

如果不想用了，删容器即可，干干净净不留残留：

bash
# 停止并删除容器
docker stop oracle12c
docker rm oracle12c

# 如果想连镜像也删掉
docker rmi gvenzl/oracle-xe:21-full

比 Windows 卸载简单太多了——这是 Docker 方案的另一大优势。

2.4 卸载 Oracle ​

装出问题了想重装？卸载 Oracle 需要比普通软件多几个步骤，因为 Oracle 在注册表里写了很多东西。

2.4.1 Windows 卸载步骤 ​

第一步：停止所有 Oracle 服务

Win+R → 输入 services.msc → 找到所有以 Oracle 开头的服务 → 逐一右键 → 停止。

第二步：使用卸载工具

进入 Oracle 安装目录，找到 deinstall.bat（一般在 \product\12.2.0\dbhome_1\deinstall\ 下），以管理员身份运行。

按照提示输入数据库信息，它会自动清理大部分文件和服务。

第三步：手动清理残留

删除以下目录（如果还存在的话）：

  • Oracle 安装目录（比如 D:\app\oracle）
  • C:\Program Files\Oracle
  • C:\ProgramData\Oracle（这是个隐藏文件夹，需要在文件管理器中开启 "显示隐藏文件"）

第四步：清理注册表

操作注册表前建议先备份。Win+R → regedit → 文件 → 导出 → 保存一份 .reg 文件。

删除以下注册表项（如果存在）：

  • HKEY_LOCAL_MACHINE\SOFTWARE\Oracle
  • HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services 下所有 Oracle 开头的项
  • HKEY_CURRENT_USER\Software\Oracle

第五步：重启电脑

重启后就可以重新安装了。

2.4.2 卸载常见问题 ​

问题解决方法
服务删不掉先重启电脑，进入安全模式再删除
注册表项删不掉右键注册表项 → 权限 → 把自己设为 "完全控制"
重新安装时提示已存在说明没卸干净，返回第三步检查残留文件

2.5 Oracle 自带工具介绍 ​

安装完 Oracle 后，你有三个工具可以用：

2.5.1 SQL*Plus ​

SQL*Plus 是 Oracle 最经典的命令行工具——黑底白字，没有鼠标，全靠敲键盘。

打开方式：开始菜单 → 找到 Oracle - OraDB12Home1 → SQL Plus

sql
-- 连接数据库
SQL> CONNECT system/Oracle123@orcl

-- 试试第一条 SQL
SQL> SELECT * FROM dual;

D
-
X
  • dual 是 Oracle 内置的"哑表"（只有一行一列），专门用来做测试
  • 如果你看到输出了一个 X，说明一切正常

SQL*Plus 常用命令：

命令作用
CONNECT 用户名/密码@数据库名连接数据库
SELECT * FROM 表名;查询数据
DESC 表名;查看表结构
exit 或 quit退出

优缺点：

  • ✅ 任何有 Oracle 的地方都有它，轻量无依赖
  • ❌ 纯文本界面，不能鼠标点，不能看图形化执行计划

2.5.2 SQL Developer ​

SQL Developer 是 Oracle 官方免费的图形化管理工具，比 SQL*Plus 友好很多。

打开方式：开始菜单 → SQL Developer。首次启动需要选择 JDK 路径，Oracle 安装时自带了一个，直接确认即可。

新建连接：

  1. 点击左侧 Connections 面板的 "+" 号
  2. 填写连接信息：
    • Connection Name：随便起，比如 orcl_12c
    • Username：system
    • Password：安装时设的密码
    • Hostname：localhost
    • Port：1521（Oracle 默认端口）
    • SID：orcl
  3. 点 Test 测试连接，状态为 "Success" 后点 Save 保存

推荐：本教程后面的大部分 SQL 练习都用 SQL Developer，因为它写代码有高亮、有自动补全、结果表格展示——对新手非常友好。而且是 Oracle 官方出品，100% 兼容，不用额外装驱动。

2.5.3 Navicat ​

Navicat 是一款流行的第三方数据库管理工具，也支持连接 Oracle。需要安装 Navicat for Oracle 或 Navicat Premium（Premium 是全能版，同时支持 MySQL、PostgreSQL 等）。

新建 Oracle 连接：

  1. 打开 Navicat → 点击左上角 "连接" → 选择 "Oracle"
  2. 填写连接信息：
字段Windows 用户Mac Docker 用户
连接名随便起，比如 orcl本地随便起，比如 oracle-docker
主机localhostlocalhost
端口15211521
服务名orclXE
用户名systemsystem
密码安装时设的密码Oracle123（启动容器时设的）
  1. 点 "测试连接"，绿色对勾出现即成功

常见踩坑：

  • Navicat 连接 Oracle 需要 OCI 驱动（Oracle Call Interface）。如果测试连接时提示 "Cannot load OCI DLL"，需要去 Oracle 官网下载 Instant Client，然后在 Navicat 设置里指定 oci.dll 路径。
  • 如果嫌装 OCI 麻烦，可以直接用 SQL Developer——它自带驱动，开箱即用。

建议：新手优先用 SQL Developer 入门，免去驱动配置的折腾。等熟悉了 Oracle，再换 Navicat 也不迟。

2.5.4 Oracle Enterprise Manager（OEM） ​

OEM 是一个 Web 界面的管理工具，打开浏览器就能用。

访问地址：https://localhost:5500/em

注意是 https，不是 http。首次访问浏览器会提示不安全，点 "高级" → "继续访问" 即可。

登录信息：

  • 用户名：system
  • 密码：安装时设的管理口令
  • 勾选 "as SYSDBA"（如果你需要管理员权限）

OEM 能做什么：

  • 查看数据库状态（CPU、内存使用、会话数）
  • 管理表空间（创建、扩容、删除）
  • 查看性能报告
  • 管理用户和权限

对于新手来说，OEM 最大的价值是可视化地看数据库运行状态——不用记命令，点点鼠标就能看到所有表空间还剩多少空间。

本章小结 ​

知识点一句话总结
安装要求64 位 Windows，至少 4GB 内存，路径不要有中文
安装关键步骤选 "桌面类" + 记住管理口令 + 环境检查警告可忽略
验证安装sqlplus / as sysdba 看到 SQL> 提示符即成功
卸载要点停服务 → 运行 deinstall → 手动删残留文件 → 清理注册表
三种工具SQL*Plus（命令行）、SQL Developer（图形化开发）、OEM（Web 管理）
推荐工具本教程练习首选 SQL Developer
