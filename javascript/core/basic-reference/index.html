基本引用类型 ​

理解 Date、RegExp 的使用方式，以及 JavaScript 中一个重要的幕后机制——原始值包装类型（为什么 'hello'.length 能正常工作？）。

Date — 处理日期和时间 ​

创建日期对象 ​

javascript
let now = new Date(); // 当前时间
let date1 = new Date(0); // Unix 纪元：1970-01-01 00:00:00
let date2 = new Date('2025-06-15'); // 从日期字符串解析
let date3 = new Date(2025, 5, 15); // 2025年6月15日（月份从0开始！）

注意： 用数字参数时，月份从 0（1月）到 11（12月）——这是 JavaScript 日期中最容易出错的点。

获取时间戳 ​

时间戳是从 1970-01-01 00:00:00 UTC 到指定时间的毫秒数：

javascript
// 获取当前时间戳的三种方式
Date.now(); // 最推荐（ES5）
new Date().getTime(); // 传统方式
+new Date(); // 利用一元 + 转换

时间戳常用于计算时间差、生成唯一 ID、设置缓存过期等场景。

常用获取方法 ​

javascript
let d = new Date();

d.getFullYear(); // 2025 —— 年份（四位数）
d.getMonth(); // 5 —— 月份（0-11，6月 = 5）
d.getDate(); // 15 —— 日（1-31）
d.getDay(); // 0 —— 星期几（0=周日，6=周六）
d.getHours(); // 小时（0-23）
d.getMinutes(); // 分钟（0-59）
d.getSeconds(); // 秒（0-59）

// UTC 版本（不受时区影响）
d.getUTCFullYear();
d.getUTCHours();

每个 get 方法都有对应的 set 方法（如 setFullYear()、setHours()），用于修改日期。

格式化输出 ​

javascript
let d = new Date(2025, 5, 15, 14, 30);

d.toString(); // 带时区的完整字符串
d.toDateString(); // 只含日期部分
d.toTimeString(); // 只含时间部分
d.toISOString(); // '2025-06-15T06:30:00.000Z'（ISO 8601 格式）
d.toLocaleDateString('zh-CN'); // '2025/6/15'（本地化日期）
d.toLocaleTimeString('zh-CN'); // '14:30:00'（本地化时间）

toISOString() 是最可靠的跨平台日期传输格式——它是 UTC 时区且格式固定，后端和数据库都能正确解析。

RegExp — 正则表达式 ​

正则表达式是用一种"匹配模式"来描述、查找、替换文本的工具。

创建正则 ​

javascript
// 字面量写法（最常用）
let re1 = /abc/;
let re2 = /abc/gi; // g=全局匹配, i=忽略大小写

// 构造函数写法（适合动态生成模式）
let re3 = new RegExp('abc', 'gi');

六个标志 ​

标志含义
g全局匹配——找出所有匹配项，而不是在第一个匹配后停止
i忽略大小写
m多行模式——^ 和 $ 匹配每行的开头和结尾
uUnicode 模式——正确处理代理对字符（如 emoji）
y粘滞模式——只从 lastIndex 位置开始匹配
sdotAll 模式——. 也能匹配换行符 \n

两个核心方法 ​

javascript
let str = '联系方式：abc@example.com 和 xyz@test.com';

// test() —— 判断是否匹配，返回布尔值
/@/.test(str); // true

// exec() —— 返回匹配详情（分组捕获等），通常配合 g 标志循环使用
let re = /(\w+)@([\w.]+)/g;
let match;
while ((match = re.exec(str)) !== null) {
  console.log(match[0]); // 完整匹配：'abc@example.com'
  console.log(match[1]); // 第一个捕获组：'abc'
  console.log(match[2]); // 第二个捕获组：'example.com'
}

字符串的正则方法 ​

字符串本身也有四个配合正则的方法，日常开发中比 exec() 更常用：

javascript
let str = 'abc123def456';

str.search(/\d/); // 3 —— 第一个数字的位置
str.match(/\d+/g); // ['123', '456'] —— 所有数字
str.replace(/\d+/g, 'NUM'); // 'abcNUMdefNUM' —— 替换
str.split(/\d+/); // ['abc', 'def', ''] —— 按数字分割

常见模式速记 ​

javascript
\d      // 数字 [0-9]
\w      // 单词字符 [a-zA-Z0-9_]
\s      // 空白字符
.       // 任意字符（除换行）
+       // 一个或多个
*       // 零个或多个
?       // 零个或一个
{n}     // 恰好 n 个
{n,}    // 至少 n 个
^       // 开头
$       // 结尾
[abc]   // 字符组：a、b 或 c
[^abc]  // 取反：不是 a、b、c
(a|b)   // a 或 b

正则的完整语法可以写一整本书，这里只覆盖最常用的部分。遇到具体匹配需求时查文档即可。

原始值包装类型 — 一个重要的幕后机制 ​

先看一个现象：

javascript
let s = 'hello';
console.log(s.length); // 5 —— 原始字符串怎么有属性？
console.log(s.toUpperCase()); // 'HELLO' —— 原始字符串怎么有方法？

字符串是原始类型，按理说不应该有属性和方法。但 JavaScript 在背后做了一个"装箱"操作：

当你写 s.length 时，JS 引擎实际做了：
1. let temp = new String('hello');  ← 临时创建一个 String 对象
2. 访问 temp.length                ← 在临时对象上读取 length
3. 销毁 temp                        ← 临时对象立即被回收

整个过程对开发者透明，这就是为什么原始值能像对象一样访问属性和方法。三种包装类型分别是：

原始类型包装类型示例
stringString'hello'.length
numberNumber(123).toFixed(2)
booleanBooleantrue.toString()

不要显式创建包装对象 ​

javascript
let str1 = 'hello'; // 原始字符串
let str2 = new String('hello'); // String 对象（不要这样做！）

typeof str1; // 'string'
typeof str2; // 'object'

// 对象永远是 truthy，即使包裹了 false
let falseObj = new Boolean(false);
Boolean(falseObj); // true！（因为它是对象）
if (falseObj) {
  console.log('执行了');
} // 会执行！这是个陷阱

结论：永远用原始值，让 JavaScript 自动处理装箱。不要用 new String()、new Number()、new Boolean()。

Number 包装类型的补充 ​

Number 的基础用法已在基础篇覆盖，这里补充两个包装类型特有的方法：

javascript
// 判断特殊值（比全局 isNaN/isFinite 更严格，不做类型转换）
Number.isNaN(NaN); // true
Number.isNaN('hello'); // false —— 不转类型，直接判断

Number.isFinite(123); // true
Number.isFinite(Infinity); // false
Number.isFinite('123'); // false —— 不转类型

// 判断整数
Number.isInteger(5); // true
Number.isInteger(5.0); // true
Number.isInteger(5.1); // false

// 判断安全整数（在 ±2^53 范围内）
Number.isSafeInteger(9007199254740991); // true
Number.isSafeInteger(9007199254740992); // false

Global — 全局对象 ​

浏览器中的 Global 对象就是 window。所有在全局作用域中定义的 var 变量和 function 函数，都会成为 window 的属性或方法。

window 对象承载了很多"看起来不像任何对象方法"的全局函数，实际上它们都是 Global 对象的方法：

URL 编码 ​

URL 中不能直接包含中文、空格等字符，需要编码：

javascript
// encodeURI：编码整个 URL，保留 : / ? # 等 URL 结构字符
encodeURI('https://example.com/搜索?q=JavaScript 教程');
// 'https://example.com/%E6%90%9C%E7%B4%A2?q=JavaScript%20%E6%95%99%E7%A8%8B'

// encodeURIComponent：编码 URL 参数值，连 = & / 也会编码
encodeURIComponent('JavaScript 教程');
// 'JavaScript%20%E6%95%99%E7%A8%8B'

// 什么时候用哪个？
// encodeURI → 编码整个链接
// encodeURIComponent → 编码 URL 的查询参数部分的值

// 对应的解码方法
decodeURI(encodedURI);
decodeURIComponent(encodedComponent);

eval — 执行字符串中的代码 ​

javascript
eval('let x = 10; console.log(x);'); // 10
eval('2 + 2'); // 4

eval 是一个非常危险的方法——它会在当前作用域中执行任意代码字符串，可能被恶意利用（XSS 攻击）。永远不要在生产代码中使用 eval，了解它只是为了看懂旧代码。如果参数不是字符串，eval 原样返回。

其他全局方法 ​

javascript
// 已在前面章节介绍过的全局方法
parseInt('42px'); // 字符串转整数
parseFloat('3.14em'); // 字符串转浮点数
isNaN(NaN); // 判断是否 NaN
isFinite(123); // 判断是否有限数值

Math — 数学工具 ​

Math 是一个静态对象（不是构造函数），直接调用上面的方法，不需要 new：

javascript
// 取整四兄弟
Math.ceil(3.1); // 4 —— 向上取整
Math.floor(3.9); // 3 —— 向下取整
Math.round(3.5); // 4 —— 四舍五入
Math.trunc(3.9); // 3 —— 去掉小数部分（ES6）

// 最值
Math.max(1, 2, 3); // 3
Math.min(1, 2, 3); // 1

// 随机数：0（含）到 1（不含）之间的浮点数
Math.random(); // 0.582376...

// 生成 [min, max] 之间的随机整数
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
randomInt(1, 10); // 1~10 之间的随机整数

// 数学常数
Math.PI; // 3.141592653589793
Math.E; // 2.718281828459045

// 幂运算与开方
Math.pow(2, 3); // 8（2的3次方，ES6 有了 ** 运算符后用得少了）
Math.sqrt(16); // 4（平方根）
Math.abs(-5); // 5（绝对值）

本章小结 ​

  • Date 用于日期时间操作，注意月份从 0 开始。Date.now() 获取时间戳，toISOString() 是可靠跨平台格式
  • encodeURI() 编码整个 URL，encodeURIComponent() 编码参数值；eval() 极其危险，永远不要在生产代码中使用
  • RegExp 用模式匹配文本，test() 判断匹配，match() 提取内容，replace() 替换
  • 原始值包装类型：JS 自动将原始值装箱为临时对象来访问属性/方法，用完即销毁。不要显式 new String/Number/Boolean
  • Number.isNaN() 比全局 isNaN() 更严格（不做类型转换）
  • Math 是静态对象，提供了取整、随机数、数学常数等工具
