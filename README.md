# 炊烟小站 🏠

> 一隅之地，记录技术与成长

[![Website](https://img.shields.io/badge/站点-docs.yychuiyan.com-667eea?style=flat-square)](https://docs.yychuiyan.com) [![VitePress](https://img.shields.io/badge/VitePress-1.6-5c73e7?style=flat-square&logo=vitepress)](https://vitepress.dev)

个人技术文档站点，基于 VitePress 构建。内容涵盖从入门到进阶的教程体系，以及日常开发中的踩坑记录与工具分享。

## 📚 内容导航

| 栏目            | 说明                                                                 |
| --------------- | -------------------------------------------------------------------- |
| 📖 **教程文档** | 系统化学习路径：Git、MySQL、Python、JavaScript、自动化测试、性能测试 |
| ✍️ **个人博客** | 开发踩坑、工具配置、技术随笔                                         |
| 🛠️ **作品集**   | 个人项目展示                                                         |
| 🌻 **乐观生活** | 网文小说与生活随笔                                                   |
| 🔗 **网站导航** | 常用工具、产品、AI 资源导航                                          |

## 🛠 技术栈

- **框架**：VitePress
- **搜索**：Pagefind（支持中文分词）
- **评论**：Waline
- **部署**：GitHub Pages + GitHub Actions
- **统计**：百度统计
